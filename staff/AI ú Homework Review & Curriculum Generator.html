Medium 1. Explain the divide-and-conquer approach used in merge sort. How does it compare to quick sort?
Merge sort divides the array into halves recursively, then merges sorted halves. Quick sort partitions around a pivot. Merge sort is stable and O(n log n) worst-case, quick sort is faster in practice but O(n²) worst-case.
Hard 2. What is the time complexity of heap sort? Explain the heapify process and its role.
Heap sort runs in O(n log n) time. Heapify builds a max-heap from an array in O(n) time, then repeatedly extracts the maximum element and reheapifies, resulting in O(n log n) overall.
Easy 3. Describe the basic concept of a sorting algorithm. Why is sorting important in computer science?
A sorting algorithm arranges elements in a specific order (ascending/descending). Sorting enables efficient searching, data organization, and is a fundamental building block for many algorithms.
Medium 4. Compare and contrast the space complexity of merge sort and quick sort.
Merge sort uses O(n) auxiliary space due to temporary arrays. Quick sort uses O(log n) space for the recursive call stack (in-place partitioning).
Hard 5. Implement a function to find the k-th smallest element in an unsorted array using quickselect.
Quickselect uses partitioning similar to quick sort but only recurses into the partition containing the k-th element. Average O(n) time, worst-case O(n²).
